How This Site Was Made

Dariya handled the "Order" and "About" sections, Alina did the reviews, and Zhansaya worked on the catalog and "Contacts." We divided the tasks up—some people worked on specific sections while someone else set up the repository. We all used Visual Studio Code and Git for collaboration, pushing our changes as we went. The biggest challenge was getting the semantics right without CSS. It was tricky deciding when to use a <section> versus a <div>, or keeping the navigation bar consistent across all eight pages without the layout breaking; we also had to rethink the structure once we realized some of the "Delivery" HTML pages were unnecessary. We solved this by simply removing the redundant elements. As for the specific tasks: we worked on the README together, Zhansaya did the index page, Dariya handled the colophon, and Alina took care of the rest. Later, we each took on two pages, and we worked on the log list together.

Tools

The site was written by hand, without frameworks or generators, in a text editor.

  • Code editor: VS Code
  • Version control: git
  • Validation: W3C Validator

Terminal Example

To clone the repository and open the site locally, this command was used:

git clone git@github.com:dardau/clothing_store.git
cd clothing_store

Each file was opened directly in the browser — just press Ctrl + O in the browser and pick the HTML file you need.

There should be no errors when checking the browser console; normally it’s empty, and on a successful page load you might see something like:
Document loaded, no errors found.
